# 설명 대본 시안 (초등 고학년 기준)

2026-10-29. 지금 앱 문구의 아쉬운 점과, 고를 수 있는 대본 3개. 고르면 그 대본대로 앱 문구를 바꾼다.

## 지금 문구의 아쉬운 점

- 안내 3장이 "규칙 설명"으로 끝난다. 왜 이게 신기한 일인지(이기는 법을 가르쳐 주지 않았는데 배운다)가 빠져 있다.
- 놀이 중 문구가 상황 중계에 그친다. 학생이 생각할 거리(어디가 나올까, 왜 그 칸일까)를 주지 않는다.
- 배우는 순간이 "구슬 +3"에서 멈춘다. 그래서 다음 판이 어떻게 달라지는지가 없다.
- 결과 화면의 "이게 강화학습이에요"가 갑자기 어려운 말로 끝난다. 오늘 한 일과 요즘 AI가 이어지지 않는다.

## 대본 A — "오늘 내가 AI 선생님"

관점: AI는 아무것도 모른 채 태어났고, 내 승패가 AI의 수업이다. 핵심 메시지 "AI는 정답을 배운 게 아니라, 내가 준 상과 벌로 스스로 고친다."

| 화면 | 문구 |
| --- | --- |
| 대기 | 이 AI는 이기는 법을 모른 채 태어났어요. 오늘 내가 가르쳐 볼까요? / 화면을 누르면 시작해요 / 오늘 AI를 가르친 판 N |
| 안내 1 · 아무것도 모르는 기계 | 1961년, 컴퓨터가 방 하나만 하던 시절. 영국의 과학자 도널드 미치는 성냥갑 304개와 색 구슬로 틱택토를 두는 기계를 만들었어요. 이 기계는 규칙도, 이기는 법도 몰랐어요. 그냥 구슬을 꺼낼 뿐이었죠. |
| 안내 2 · 구슬 수가 곧 마음 | 판 모양마다 성냥갑이 하나씩 있어요. 상자 속에는 둘 수 있는 칸마다 구슬이 들어 있고, AI는 구슬 하나를 꺼내 그 칸에 둬요. 구슬이 많은 칸일수록 자주 나와요. 그러니까 구슬 수는 "AI가 그 칸을 얼마나 좋아하는지"예요. |
| 안내 3 · 가르치는 방법은 상과 벌 | 판이 끝나면 AI가 쓴 상자에 구슬을 고쳐 넣어요. AI가 이기면 그 칸에 3개 더(상), 비기면 1개 더, 지면 1개를 빼요(벌). 이게 전부예요. 누구도 이기는 법을 알려 주지 않지만, 수백 판을 두면 AI는 지는 수를 점점 안 두게 돼요. 오늘 내가 두는 판도 AI의 수업이에요. |
| 놀이 · AI 차례 | AI 차례예요. 지금 판 모양의 성냥갑을 찾아요. |
| 놀이 · 상자 열림 | 상자를 열었어요. 어느 칸에 구슬이 제일 많은지 보세요. |
| 놀이 · 구슬 나옴 | 구슬 하나가 나왔어요. AI는 {칸}에 둬요. |
| 놀이 · 내 차례 | 내 차례예요. 빈칸을 눌러 ×를 둬요. |
| 놀이 · 판 끝 | 내가 이겼어요. AI가 지는 수를 배울 차례예요. / AI가 이겼어요. 이 수를 더 좋아하게 돼요. / 비겼어요. 비기는 것도 AI에겐 작은 상이에요. |
| 성냥갑 캡션 · 아래 띠 | 구슬이 많을수록 AI가 좋아하는 칸 / 구슬 수 = AI가 그 칸을 좋아하는 정도 |
| 배우는 순간 · 제목 | AI의 수업 시간 |
| 배우는 순간 · 짐 | AI가 졌어요. 이번에 쓴 칸마다 구슬을 1개씩 뺐어요. 다음 친구와 둘 때 이 수는 조금 덜 나와요. 내가 AI에게 "그 수는 안 돼"를 가르친 거예요. |
| 배우는 순간 · 이김 | AI가 이겼어요. 이번에 쓴 칸마다 구슬을 3개씩 넣었어요. 이 수는 앞으로 더 자주 나와요. 내가 AI에게 "그 수는 좋아"를 가르친 거예요. |
| 배우는 순간 · 비김 | 비겼어요. 이번에 쓴 칸마다 구슬을 1개씩 넣었어요. 지지 않은 것도 AI에겐 배울 거리예요. |
| 결과 · 제목 | 오늘의 수업 결과 |
| 결과 · 카드 1 "내가 바꾼 구슬" | 늘어난 구슬 N개 · 빠진 구슬 N개. (내가 이겼을 때) 내가 이긴 수의 구슬이 빠졌어요. AI는 다음 친구에게 그 수를 덜 둘 거예요. 내가 AI를 조금 더 똑똑하게 만들었어요. / (AI가 이겼을 때) AI가 이긴 수에 구슬이 늘었어요. AI는 그 수를 더 자주 둘 거예요. / (다 비겼을 때) 비긴 수에도 구슬이 늘었어요. AI는 먼저 지지 않는 법부터 배워요. |
| 결과 · 카드 2 "이게 강화학습이에요" | AI는 정답을 배운 게 아니에요. 해 보고, 결과가 좋으면 더 하고, 나쁘면 덜 해요. 바둑 AI도, 게임 AI도 이렇게 수백만 판을 스스로 두며 배워요. 오늘 N판째까지 여러분이 이 AI를 함께 가르쳤어요. |

고치는 데 필요한 것: 문구만 바꾸면 된다.

## 대본 B — "구슬 수로 읽는 AI의 마음" (확률)

관점: 구슬 수 = 그 칸이 나올 확률. 상자를 열기 전에 어디가 나올지 맞혀 보고, 배운다는 것은 확률이 바뀌는 것임을 숫자로 본다. 6학년 비율 단원과 이어진다.

| 화면 | 문구 |
| --- | --- |
| 대기 | AI는 구슬을 뽑아서 둬요. 어느 칸이 나올지 맞혀 볼래요? / 화면을 누르면 시작해요 / 오늘 AI와 둔 판 N |
| 안내 1 · 뽑기로 두는 기계 | 1961년, 영국의 과학자 도널드 미치는 성냥갑 304개와 색 구슬로 틱택토 기계를 만들었어요. 컴퓨터는 없었어요. 기계가 하는 일은 딱 하나, 상자에서 구슬 하나를 꺼내는 거였어요. |
| 안내 2 · 구슬이 많으면 자주 나와요 | 상자에는 둘 수 있는 칸마다 구슬이 있어요. 가운데 칸에 8개, 구석 칸에 2개면 열 번 중 여덟 번은 가운데가 나와요. 그래서 구슬 수를 보면 AI가 어디에 둘지 미리 짐작할 수 있어요. |
| 안내 3 · 구슬이 바뀌면 확률이 바뀌어요 | 판이 끝나면 구슬을 고쳐 넣어요. 이기면 3개 더, 비기면 1개 더, 지면 1개를 빼요. 좋은 수는 구슬이 늘어 더 자주 나오고, 나쁜 수는 줄어서 점점 안 나와요. AI가 배운다는 건 구슬 수, 그러니까 확률이 바뀌는 거예요. |
| 놀이 · AI 차례 | AI 차례예요. 상자를 열기 전에 맞혀 보세요. 어느 칸이 나올까요? |
| 놀이 · 상자 열림 | 상자를 열었어요. 구슬이 가장 많은 칸은 어디인가요? |
| 놀이 · 구슬 나옴 | {칸} 구슬이 나왔어요. 전체 N개 중 M개, 열 번 열면 K번쯤 나오는 칸이에요. |
| 놀이 · 내 차례 | 내 차례예요. 빈칸을 눌러 ×를 둬요. |
| 놀이 · 판 끝 | 내가 이겼어요. AI가 쓴 칸의 구슬이 줄어요. / AI가 이겼어요. AI가 쓴 칸의 구슬이 늘어요. / 비겼어요. 구슬이 조금 늘어요. |
| 성냥갑 캡션 · 아래 띠 | 칸마다 구슬 몇 개 · 전체 N개 (칸마다 % 표시를 기본으로 켬) / 구슬 수 ÷ 전체 = 그 칸이 나올 확률 |
| 배우는 순간 · 제목 | 확률이 바뀌는 순간 |
| 배우는 순간 · 짐 | AI가 졌어요. 쓴 칸마다 구슬 1개를 뺐어요. 이 칸이 나올 확률이 조금 낮아졌어요. |
| 배우는 순간 · 이김 | AI가 이겼어요. 쓴 칸마다 구슬 3개를 넣었어요. 이 칸이 나올 확률이 커졌어요. |
| 배우는 순간 · 비김 | 비겼어요. 쓴 칸마다 구슬 1개를 넣었어요. 조금 더 자주 나와요. |
| 배우는 순간 · 카드 | 8 ▸ 11 아래에 "24개 중 8개 → 27개 중 11개"를 작게 붙인다. |
| 결과 · 제목 | 오늘의 대결 결과 |
| 결과 · 카드 1 "나와 둔 판으로 바뀐 확률" | 늘어난 구슬 N개 · 빠진 구슬 N개. AI가 둔 수 중 좋은 수는 더 잘 나오게, 나쁜 수는 덜 나오게 바뀌었어요. |
| 결과 · 카드 2 "AI가 배운다는 건" | 정답을 외우는 게 아니라, 해 본 결과로 확률을 고치는 거예요. 요즘 AI도 구슬 대신 숫자를 쓸 뿐, 똑같이 배워요. 오늘 N판째까지 여러분이 함께 확률을 바꿨어요. |

고치는 데 필요한 것: 문구 + 놀이 문구에 "N개 중 M개" 숫자 넣기(구슬 수는 이미 있어서 쉬움) + % 표시 기본 켜기 + 배우는 순간 카드에 한 줄 추가.

## 대본 C — "1961년 실험실 조수"

관점: 학생은 미치 박사의 조수. 기계에 상과 벌을 주는 역할을 맡고, 마지막에 1961년 기계와 요즘 AI를 잇는다. 이야기와 역사가 중심.

## 추천

A. 강화학습의 핵심("정답을 가르쳐 준 적 없는데 상과 벌만으로 배운다")이 가장 또렷하고, 학생이 "내가 가르쳤다"는 느낌을 받는다. B의 "전체 N개 중 M개" 한 줄을 A의 놀이 문구에 섞어도 좋다.
