# 성냥갑 AI

1961년 도널드 미치가 성냥갑 304개와 구슬로 만든 틱택토 기계(MENACE)를 다시 만든 체험 프로그램입니다. 학생이 약 4분 동안 구슬로 상과 벌을 주면서, AI가 배우는 원리(강화학습)를 익힙니다. Godot 4로 만들었습니다.

- 해 보기: https://web-one-omega-60.vercel.app
- 흐름: 1단계 새내기 AI → 내 손으로 상과 벌 → 2단계 연습생 AI(맞혀 보기) → 빨리 감기(AI 혼자 200판) → 3단계 졸업 시험 → 졸업장
- 선생님 메뉴: 오른쪽 위 자물쇠, 기본 비밀번호 `admin` (메뉴에서 바꿀 수 있습니다). 제목 옆 i 단추에 교사용 안내가 있습니다.

## 실행

Godot 4.7로 이 폴더를 열어 실행하거나, Windows에서는 `run.bat`을 실행합니다. 만드는 방법과 구조는 `CLAUDE.md`에 있습니다.
